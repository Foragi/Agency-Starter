# 27 - AGENTS.md

O `AGENTS.md` funciona como o **manual de operação dos agentes de código**.

Ele deve explicar aos agentes:

- como o projeto está estruturado;
- quais tecnologias utilizar;
- padrões de código;
- regras de componentes;
- regras de responsividade;
- regras de acessibilidade;
- regras de performance;
- convenções de nomenclatura;
- como criar novos componentes;
- como reutilizar componentes existentes;
- como lidar com animações;
- o que evitar;
- como testar alterações;
- como manter a arquitetura.

### Objetivo

Quando **Claude Code ou Codex** entrar no projeto, ele deve conseguir entender rapidamente:

> **“Como este projeto funciona e quais regras preciso seguir?”**
>
