# 12 - Sistema de Animações

O Starter possui animações reutilizáveis utilizando **Motion + GSAP**.

Exemplos:

- fade in;
- reveal;
- text reveal;
- stagger;
- parallax;
- magnetic button;
- hover effects;
- page transitions;
- scroll animations;
- marquee;
- cursor interactions;
- animações de entrada;
- microinterações.

### Princípio

> Animação deve melhorar a experiência, não competir com o conteúdo.
> 

Evitar:

- excesso de animações;
- animações lentas;
- efeitos sem função;
- impacto negativo na performance;
- experiências ruins em mobile.
