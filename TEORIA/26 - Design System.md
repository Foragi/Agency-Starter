# 26 - Design System

O Agency Starter possui um sistema de design evolutivo.

O arquivo:

```
DESIGN.md
```

define as regras visuais do projeto.

Deve documentar:

- cores;
- tipografia;
- espaçamento;
- grid;
- border radius;
- sombras;
- componentes;
- botões;
- estados;
- animações;
- responsividade;
- princípios visuais.

Cada cliente pode possuir seu próprio `DESIGN.md`.
