# 07 - Biblioteca de Componentes

O Agency Starter possui uma biblioteca própria de componentes reutilizáveis.

### Componentes

- Navbar;
- Header;
- Footer;
- Buttons;
- Cards;
- Forms;
- Inputs;
- Modals;
- Accordions;
- Tabs;
- Marquees;
- Badges;
- Testimonials;
- Pricing cards;
- Feature cards;
- CTA components;
- elementos de navegação;
- componentes interativos.

A biblioteca deve ser continuamente aprimorada.

> **Regra:** quando um componente for desenvolvido diversas vezes, avaliar se ele deve ser incorporado ao Agency Starter.
