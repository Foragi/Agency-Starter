# 21 - Performance

Performance é requisito estrutural, não uma etapa posterior.

Priorizar:

- Server Components quando apropriado;
- otimização de imagens;
- lazy loading;
- redução de JavaScript desnecessário;
- carregamento eficiente de fontes;
- animações performáticas;
- evitar dependências desnecessárias;
- Core Web Vitals;
- carregamento rápido em mobile.
