# 02 - Filosofia

O Agency Starter segue quatro princípios:

### 1. Reutilização

Tudo que puder ser transformado em componente, seção, animação, padrão ou sistema deve ser reutilizável.

### 2. Evolução contínua

O Starter não é um template estático.

Cada projeto pode gerar melhorias que posteriormente retornam para a base.

**Cliente → Projeto → Aprendizado → Melhoria → Agency Starter**

### 3. Qualidade premium

O objetivo não é apenas produzir sites rapidamente, mas criar experiências digitais com:

- design sofisticado;
- excelente UX;
- animações bem executadas;
- código organizado;
- alta performance;
- responsividade;
- acessibilidade;
- SEO;
- boa arquitetura técnica.

### 4. Velocidade sem sacrificar qualidade

A infraestrutura, componentes e padrões recorrentes ficam pré-configurados para que o trabalho se concentre no que realmente muda entre os clientes:

**estratégia + posicionamento + copy + design + experiência.**
