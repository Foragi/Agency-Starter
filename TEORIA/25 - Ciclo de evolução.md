# 24 - Ciclo de evolução

O Agency Starter deve funcionar como um sistema vivo.

```
Agency Starter
      ↓
Projeto do Cliente
      ↓
Desenvolvimento
      ↓
Novos componentes
      ↓
Novas soluções
      ↓
Refinamento
      ↓
Incorporação ao Starter
      ↓
Agency Starter melhor
      ↓
Próximo Cliente
```

O objetivo é que **cada projeto torne o próximo projeto mais rápido, melhor e mais sofisticado.**
