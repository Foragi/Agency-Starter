# 22 - PROJECT.md

O `PROJECT.md` contém as informações específicas de cada cliente/projeto.

Exemplo:

```
# Projeto

Cliente:
Clínica Aurora

Segmento:
Estética

Objetivo:
Gerar agendamentos.

Público:
Mulheres 25-45.

Posicionamento:
Premium, sofisticado, acolhedor.

CTA principal:
Agendar avaliação.

Páginas:

/
 /tratamentos
 /sobre
 /contato
```

O `PROJECT.md` responde:

**O que estamos construindo e por quê?**
